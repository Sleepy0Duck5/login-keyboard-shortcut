# login-keyboard-shortcut

웹페이지에서 `Ctrl+Shift+U`를 누르면 로그인 링크 또는 버튼을 찾아 실행하는 사용자 스크립트입니다.

## 기능

- `로그인`, `Log in`, `Sign in` 문구와 URL, 접근성 속성, 폼 구조를 종합해 로그인 요소 탐지
- URL 이동 성공, 이동 실패, 로그인 요소 탐지 실패 결과를 3초간 표시
- `href`가 없는 JavaScript 기반 로그인 버튼 지원
- 연속 리디렉션 이후에도 이동 성공 알림 표시
- 결과 알림을 클릭하면 스크립트 이름과 버전 확인

## 설치

1. [login-keyboard-shortcut.user.js](https://raw.githubusercontent.com/Sleepy0Duck5/login-keyboard-shortcut/main/login-keyboard-shortcut.user.js)를 엽니다.
2. AdGuard 또는 호환 사용자 스크립트 관리자에 추가합니다.
3. 웹페이지를 새로고침합니다.

Chrome 138 이상에서 AdGuard Browser Extension을 사용한다면 확장 프로그램 세부정보에서 **사용자 스크립트 허용**을 활성화해야 합니다.

## 사용법

웹페이지에 포커스가 있는 상태에서 `Ctrl+Shift+U`를 누릅니다.
